How to Use

홈페이지 · 웹

헤더에 01-primary-transparent.svg (라이트) 또는 02-reversed-transparent.svg (다크) 사용. CSS는 height: 32px; width: auto;.

Favicon · 탭 아이콘

11-favicon.svg 또는 11-favicon-32.png. SVG favicon은 <link rel="icon" type="image/svg+xml">로 지정.

앱 아이콘 · iOS / Android

03-app-icon-navy.svg 512px PNG. PWA 매니페스트에는 192px·512px 두 사이즈 등록.

소셜 미디어 프로필

07-circle-avatar.svg 512px PNG. 자동 원형 crop이 되므로 안전. 텍스트가 잘리지 않음.

명함 · 인쇄물

01-primary-transparent.svg (컬러) 또는 08-monochrome-ink.svg (1색). 인쇄 시 SVG 그대로 또는 1200dpi 이상 PNG.

HTML 워드마크 표기

<span>tk<span style="color: #4A90C2; font-weight: 400;">L</span>een</span> — L에만 Sky Blue 강조.

이메일 서명 · 뉴스레터

09-lockup-horizontal-light.svg 360px PNG. 이메일은 SVG 지원이 불안정하므로 PNG 권장.

최소 사용 사이즈

마크 단독: 16px (favicon 한계). 락업: 120px 너비 이상. 여백은 마크 너비의 25% 이상.
